# Personas

## Primary personas

### Teacher
- **Login:** Yes
- **Goals:** Mark daily attendance in <60s, record CBC performance levels per learning area/strand/sub-strand, add behavior/health notes, view timetable
- **Pain points:** Paper registers, re-entry for reports, intermittent connectivity, time-consuming roll-call

### School Administrator / Registrar
- **Login:** Yes
- **Goals:** Admissions, CSV imports with validation, user provisioning via email invites, term rollover with dry-run, configure academic years/terms/class levels/streams
- **Pain points:** Manual data cleanup after imports, enrollment duplicates, rollover errors

### Headteacher
- **Login:** Yes
- **Goals:** Oversight dashboards, approvals, reports by school/level/stream, address absenteeism hotspots
- **Pain points:** Delayed visibility into attendance and performance, scattered records

### Finance Officer
- **Login:** Yes
- **Goals:** Define fee structures per class/term, record payments manually or CSV, issue receipts, view per-student balance and collection rates, arrears list
- **Pain points:** Reconciliation time, guardian queries, manual statements

### Guardian
- **Login:** Yes
- **Goals:** View attendance, assessment/report cards, fee statement for linked children; receive absence and report availability notifications by email MVP
- **Pain points:** Lack of timely updates, unclear fees, difficulty contacting school

### Tenant Owner
- **Login:** Yes
- **Goals:** Create/archive/delete schools, manage owners, view all student data across tenant schools, audit log visibility
- **Pain points:** Inconsistent processes across schools, manual consolidation

## Secondary personas

### Platform Operator / Super Admin
- **Login:** Yes
- **Goals:** Create and suspend tenants, manage support access, oversee subscription billing post-MVP
- **Pain points:** Tenant isolation compliance, support escalation visibility

### Student
- **Login:** No account; short-lived token only
- **Goals:** Access assigned quizzes via system-generated token, auto-graded results linked to profile
- **Pain points:** Needs reliable token delivery, no profile management needed
