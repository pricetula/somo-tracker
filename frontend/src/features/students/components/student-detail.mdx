# Student Detail Component

## Overview

The **Student Detail** component is the primary view for displaying a student's profile in the Somotracker dashboard. It consolidates biographical information, academic data, guardian relationships, and key performance indicators (KPIs) into a single, interactive page.

## Location

- **Source:** `frontend/src/features/students/components/student-detail.tsx`
- **Documentation:** `frontend/src/features/students/components/student-detail.mdx`

## Purpose

Provide a comprehensive, editable profile page that replaces the current placeholder UI. The page enables:

- Viewing core student data (name, admission number, DOB, gender, address, contact info)
- Accessing academic history and enrollment records
- Managing personal details via inline forms
- Viewing real-time KPIs (attendance, punctuality, engagement)
- Editing student metadata directly from the UI

## Key Features

| Feature               | Description                                                                             |
| --------------------- | --------------------------------------------------------------------------------------- |
| **Profile Overview**  | Summary card showing name, admission number, date of birth, gender, and contact details |
| **Academics Tab**     | Current class, enrollment history, and academic progress                                |
| **Guardians Tab**     | Linked guardian profiles with contact information                                       |
| **Stats & KPIs Tab**  | Attendance rate, tardiness, present/absent counts, trend charts                         |
| **Notes Tab**         | Internal comments and free-text notes                                                   |
| **Edit Mode**         | Inline form for updating personal details (address, phone, email, nationality)          |
| **Responsive Design** | Works on tablet and mobile devices                                                      |

### Sub-components

- **`Header`**: Displays student summary and edit button
- **`OverviewTable`**: Shows core biographical fields
- **`AcademicsTab`**: Renders class info, enrollment timeline, grades
- **`GuardiansTab`**: Lists linked guardians with contact details
- **`StatsKpisTab`**: Displays KPI cards (attendance %, tardiness, present days) plus mini-chart
- **`EditForm`**: Controlled form for updating personal fields (uses Zod validation)

## Data Flow

1. **Fetch** – `StudentDetail` receives a `studentId` via props and calls `GET /students/{id}` (backend) or uses the SWAGGER annotation (`/students/{id}`).
2. **Display** – Response data populates the header and tabs.
3. **Interaction** – Clicking **Edit** triggers a `PATCH /students/{id}` call; changes are validated via Zod and persisted.
4. **Error Handling** – Errors follow the canonical error contract (`backend/internal/api/errors.go`).

## Implementation Notes

### State Management

The component uses `React Query` for data fetching:

- `useQuery(['student', studentId], fetchStudent)`
- `useMutation(updateStudent)` for editing

### Form Handling

- Uses `React Hook Form` with `Zod` schema validation
- Controlled form with real-time validation messages
- Auto-saves when form fields are blurred

### Performance Optimizations

- Uses `React.memo` to prevent re-renders
- Implements infinite scrolling for related data where applicable
- Lazy loads heavy components like charts

### Error Handling

- Display errors at the component level, not as toasts
- Provides clear error messages and recovery actions
- Fallback content displayed during loading states
